# Mafia Server

Backend частина проєкту **Mafia**.

## Поточний статус

На цей момент папка підготовлена як стартова точка для backend-розробки.
Реалізація API та realtime-логіки ще не додані.

## Що планується тут

- REST API для кімнат, сесій та ігрового стану.
- Realtime синхронізація між гравцями (WebSocket).
- Валідація вхідних даних і базова авторизація сесії.
- Інтеграція з frontend (`mafia-client`).

## Примітка

Поточний MVP реалізований у frontend-частині.
Backend буде наступним етапом розробки.
